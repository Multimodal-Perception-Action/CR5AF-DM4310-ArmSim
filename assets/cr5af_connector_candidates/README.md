# CR5AF connector design candidates

This folder contains CAD exports and native Inventor source files from the local CR5A connector-design folder, including the older revisions. They are retained as candidate mount/connector geometry.

The parts have not been confirmed as the as-built DM-J4310-2EC V1.2 gripper mount, and their fit, clearances, and mechanical load limits have not been validated. The separate B601-DM V2 reference package is kept under `assets/reference_adapters/`.
