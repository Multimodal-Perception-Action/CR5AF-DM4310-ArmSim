# Dobot CR5AF × reBot B601-DM：V2 双片式转接法兰（工程试配稿）

日期：2026-11-03；单位：毫米。**此模型用于试配与装配验证，并非经过载荷与振动验证的可直接运行成品。**

## 为什么 V1 单片方案可能装不上

一个圆盘上的两组轴向孔位分别为机器人侧 M6/PCD50 与电机侧 M3/PCD38。如果两侧螺钉都只能从转接件内侧拧紧，固定第一侧后第二侧螺头会被遮蔽。特别是两组螺钉若角度同为45°，相邻轴中心距离仅(50-38)/2=6 mm，常见M6与M3螺头沉孔在同一面还会发生相交。不能仅凭“孔位对应”认为能装配。

## V2 结构与先后顺序

1. **A：机器人侧法兰**，Ø82 x 16厚，背面 Ø63.5 x 6.25 试配凹窝，4x Ø6.6 PCD50 45°机器人 M6 螺钉穿孔，螺头正面 Ø11.3 x 6.2 沉孔。断电时 A 独立拧到 CR5AF 原 M6 螺纹孔。试配建议M6x10圆柱头，**以螺钉实际尺寸与机械臂螺孔深度复核**（按模型名义螺纹啮合约6.2mm）。
2. **B：电机侧法兰**，Ø82 x 8厚，4x Ø3.4 贯通孔 PCD38/45°；**M3 螺头埋在 B 底面**的 Ø6.0 x3.2沉孔中。先在工作台上将B从背面固定到电机/夹爪原装连接件（前提：所测的4孔有与该方案匹配的M3螺纹，另确认螺头、中心凸台空间）。试配 M3x10 名义啮合5.2mm，但必须实测有效螺纹深度。若配合类型不是螺纹孔，需按实际螺母/螺栓结构重做。
3. **A+B 对合**：两片法兰通过 4x M4 外圈轴向螺钉连接，PCD68/0°；B 正面做 Ø7.9 x4.3沉孔，方便内六角工具在电机外缘处拧入，A上做4x M4盲孔（模型用 Ø3.3 底孔表示，**需要攻丝；打印件则按实际热熔铜螺母外径修改**）。建议 M4x10 试配，名义进入A 6.3mm；A 盲孔深7.5mm，留有底部余量。**M4孔中心距中心34mm，电机外壳及夹爪运动件不能遮住工具操作范围。**
4. **销钉定位（可选）**：两片之间设 2x Ø3.1、深3.2的销孔，PCD60，角度22.5°/202.5°，用于定位和帮助承受剪切。正式加工按实际定位销及材料指定尺寸/公差。不要让塑料M4螺孔直接承受动态夹爪工作载荷。

## 实物必须核查的项目

- 夹爪4个“直径3mm孔”究竟为 M3 内螺纹、通孔还是沉孔？从哪面可以插入螺丝？
- 电机/夹爪法兰是否有中心凸台；最大直径、凸出高度是多少？本版B中孔Ø12仅为占位值；若有中心凸台，不能强制装配。
- 电机外壳、线束与4x M4 PCD68外圈螺丝、内六角扳手的实际间距，能否旋拧。
- 机器人末端 Ø82外缘与M8航插、拖拽示教按键、力传感器密封圈是否有干涉。
- 合并后总厚度24mm，附加偏心及末端工具TCP需要重新标定。

## 材料与强度

推荐首轮用Bambu 3D打印件确认孔位、螺钉先后顺序和中心避让，**不允许作为未经测试的承载法兰上机运动**。实际机器人夹持作业推荐铝合金 CNC 两片结构、金属螺纹与防松件，并核算弯矩、螺纹有效啮合、螺钉预紧与防松、负载质心、冲击、疲劳和末端六维力传感器受力。螺钉规格在此仅为试配建议。
