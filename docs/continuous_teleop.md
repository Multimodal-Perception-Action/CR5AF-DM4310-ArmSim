# 真机连续联动

双击桌面 **U-Arm_CR5_真机联动**，或工程根目录 `start_continuous_teleop.cmd`。

1. 保持两臂在准备开始的姿态，清空活动区域，急停放在手边。
2. 在界面勾选参与跟随的关节。方向不对时，停止后勾选对应关节的“反向”。
3. 点击 **开始真机联动（持续）**。程序预检通过后使能 CR5，以当前两臂位置建立相对参考，随后按关节角增量 1:1 跟随。
4. 拨动扳机越过开闭阈值控制夹爪。启动本身不会要求夹爪开合。
5. 点击 **停止并失能**。不自动回到起点。关闭控制窗口也请求停止，并等待控制程序退出。

没有 30 秒自动结束，也没有每轴 ±5° 的会话范围限制。默认最高速度为 12°/秒，界面可在 1–20°/秒内调整；同时默认只保留 20° 的目标追赶差，快速大幅拨动不会让旧目标长时间排队。保留关节软件限位、反馈新鲜度、窗口心跳和异常停机。关节限位并不是防碰撞保护：程序没有环境避障或自碰撞规划，不能把整个机械行程视为已验证安全工作空间。

3D 窗口显示 CR5 实测关节角；夹爪开度仍是指令示意。关闭 **3D监视窗口** 不会停止真机，停止请使用控制窗口的红色按钮或实体急停。

方向更改只作用于下一轮真机控制，不改左侧 U-Arm 模型的显示方向。点击开始时，所选关节和方向保存到 `config/uarm_cr5_continuous_ui.json`，供下次打开使用。每次重新开始都会配对当前位置，不自动回零或恢复上一轮起点。

每轮日志写入 `logs/continuous_session_<时间>/` 和 `logs/uarm_cr5_control_stream_<时间>.jsonl`。有故障或串口占用时，程序拒绝开始，不会自动清错、切换控制模式、终止其他进程或重复启动。

如果 CR5 已使能但处于无报警待机状态，点击开始后程序会先失能、核实状态，再进入统一的使能与当前位置配对流程。拖拽、运动中或有报警时拒绝接管。

## 速度和关节映射

界面现在可设置每个 CR5 关节的来源 U-Arm ID、方向、角度倍率和“待应用偏置°”，并可选择 1–20°/秒的最大跟随速度，默认 12°/秒。偏置限制在 -180°到+180°，启动后按最大跟随速度逐步加入，不会瞬间跳变；安全停止时自动扣除已执行的偏置，下一次只继续剩余部分，完成后归零，避免重复启动造成累计旋转。六个来源 ID 必须各使用一次，避免两个 CR5 关节误用同一主臂关节。默认最大追赶差为 20°：如果手臂瞬间移动得比真机限速快，控制器只追赶最近的 20°，旧的排队位移被丢弃；设为 0 才会关闭此限制。每次启动仍以当前两臂位置为相对零点。
