# U-Arm Config2 模型修复与验证

更新日期：2026-11-10

## 当前结论

已修复可从 STEP 装配和零件几何确定的结构错误：整体上下方向、两根立柱和横梁的
固定归属、七个关节的输出轴心、输出轴零件归属，以及独立扳机关节。双机窗口现在加载
`simulation/generated/uarm_repaired/uarm_config2_repaired.urdf`，原始用户模型包保留。

七个关节各进行了 −90°、−45°、+45°、+90° 的离线转动检查，共 28 项通过。该结果
验证模型的结构与关节变换。已依据用户明确反馈修正 J2、J3、J4、J5 的显示方向；
绝对零偏、整体姿态、可用运动范围和碰撞安全仍未完成物理标定。真实主臂与画面姿态的
配准仍需逐轴核对，界面对此保留明确标记。

## 错误原因与修复

| 问题 | 查明的原因 | 本轮处理 |
| --- | --- | --- |
| 大块底座位于顶部 | CAD 导出坐标下，底座顶面位于最大 Z 位置 | 完整装配绕 X 轴翻转 180°，使用四元数 `[0,1,0,0]`（w,x,y,z），Z 平移 `0.167 m`，使底座落地；不改各关节内部装配关系 |
| 门形支架随末端脱离 | `sitter-1`、`sitter-2`、`sitter_mid-1` 错误合并进 `link6` | 三件从 `link6` 拆出并固定归入 `base_link` |
| 关节转动后轴与孔分离 | 旧轴线取自半径 `8.525 mm` 的内部电机壳体，而非减速器输出轴 | 重新解析 STEP 装配变换链，依据 `OUTPUTGEAR` 的 R2.95/R3 圆柱面恢复真正输出轴线；七条旧轴线均与正确轴线平行偏离约 `25.530619 mm`，已修正 |
| 轴、舵盘不随转动件一起动 | 完整舵机原先近似并入关节父侧，输出件也被固定在父侧 | 每个舵机的齿轮盘、花键轴、后轴、前舵盘、后舵盘五件移到对应子侧；七个舵机共重新归属 35 件 |
| 扳机不能独立转动 | `trigger_short-1` 原先并入 `link6`，没有独立转轴 | 新建 `trigger` 与 `trigger_joint`，围绕第七个舵机的正确输出轴运动 |
| 画面与实物方向/姿态不同 | 编码器正方向和操作者中位未与 CAD 方向、零位完整配准 | 新增独立显示校正；按用户反馈反向 J2～J5，整体姿态与绝对零偏待核对，真实控制映射不改 |

其中轴线恢复路径记录了每个舵机实例到输出齿轮的 STEP 层级，例如第一轴为
`NAUO4 → NAUO19 → NAUO20 → NAUO32`。这次修正依据输出齿轮零件和装配变换，
不再以内部电机壳体圆柱面代替关节轴。

不能替代真实轴孔的独立测量、物理限位测试或碰撞验证。±90° 仅为离线测试角度，
不代表允许真实扳机或机械臂旋转该角度。

## 显示方向与零位校正

双机窗口新增“模型显示校正（仅画面）”，可选择 J1～J6 或扳机 ID7，设置反向、
角度偏置，使用 ±1°/±5° 按钮微调，并保存显示设置。每轴方向和姿态有独立的人工
核对标记；修改方向或偏置后，该轴标记自动清除。

实现文件：[uarm_visual_registration.py](../src/uarm_visual_registration.py)。
保存位置：`config/uarm_visual_registration.json`。界面只在操作者点击“保存显示设置”时写入。
公式为 `显示角度 = 显示符号 × 输入相对角度 + 显示偏置`。

本轮已根据用户“J2、J3、J4、J5 相反”的反馈预置并保存该独立显示文件：

- J1～J6、ID7 的显示符号依次为 `[1,-1,-1,-1,-1,1,1]`。
- 显示偏置仍为 `[0,0,0,0,0,0,0]`，未据此推断绝对姿态。
- 输入中心依次为 `[116,474,3637,3703,4092,285,2966]`。
- J2～J5 方向已按反馈修正；各轴“方向和姿态均已核对”标记仍为 false，等待更新后画面
  与实物的完整配准确认。J1、J6、ID7 保留原显示符号，不新增未经反馈的反向。

该设置与 `uarm_cr5_full_calibration.json`、`uarm_dobot_teleop.json` 的真实控制配置
分开。它不修改舵机零偏、CR5 参数或真实遥操方向。保存偏置时所使用的编码器参考姿态
必须保持一致；若以后改变输入中心，需要重新核对显示偏置。保存文件同时记录输入
参考信息；参考改变或旧文件未记录参考时，界面自动清除各轴核对标记并提示复核。

已有 `[+1,-1,+1,+1,+1,+1]` 记录描述 U-Arm 编码器到 CR5 API 的遥操关系，不能直接
用作 U-Arm 编码器到 CAD 关节的显示符号。旧静态中位、J1 左右边界记录也不能单独确定
六轴 CAD 绝对姿态。只有实际姿态与画面逐轴核对后，才可标记相应显示配准完成。
