# U-Arm → CR5AF 全行程标定

## 不是把两边都设成数值0°

CR5关节数值0°不等于安全Home。当前控制器反馈J1为312.2704°，它在几何上等价于
-47.7296°，但直接切换表示可能造成整圈旋转。因此后续运动必须保留控制器当前的连续角度
表示，并把已经多次安全返回的姿态定义为Home候选。

官方CR5模型给出的硬关节范围约为：J1/J2/J4/J5/J6 ±359.82°，J3 ±160.03°。
这些只表示关节硬限，不表示无碰撞工作空间，也不能直接作为遥操作范围。

## 标定顺序

1. 记录CR5控制器原点，但不自动把全0°当作操作Home；
2. CR5保持失能、无报警，选择远离障碍物和奇异位形的安全操作Home；
3. U-Arm放在最舒服的中位，连续采样并确认该姿态为Leader Center；
4. 从中位开始，按ID1到ID6逐轴扫到两个方向的舒适极限，每轴都回中位；
5. 对CR5每轴分别设定Home两侧的安全行程，不要求左右相同；
6. 使用分段线性映射，使Leader两侧的全部舒适行程分别映射到CR5两侧的安全行程；
7. 先仿真，再按±5°、±10°、逐轴扩大、组合扩大的顺序实测；
8. 所有目标同时受官方硬限、安全余量、会话反馈包络和速度限制约束。

- 该姿态接近最高伸展，J5也在0°附近，因此暂不认定为最终操作Home；
- 先完成U-Arm中位与行程标定，再结合仿真选择操作Home和CR5安全行程。

分段映射：

```text
leader_delta < 0:
  target = robot_home + leader_delta / abs(leader_negative_span) * robot_negative_span

leader_delta >= 0:
  target = robot_home + leader_delta / leader_positive_span * robot_positive_span
```

这种方法允许主臂例如向左170°、向右135°，同时映射到CR5向左30°、向右45°，不会要求
两个机构具有相同机械行程。

## 手动范围采集

确认U-Arm位于Center后，推荐逐轴运行：

```powershell
python .\src\uarm_range_capture.py --axis 1 --duration 30
python .\src\uarm_range_capture.py --axis 2 --duration 30
# 依次到 --axis 6
```

每个窗口内只把所选轴从中位移动到负向舒适极限、正向舒适极限，再回中位。程序只读取COM7，
不会连接、使能或移动CR5，也不会写U-Arm寄存器。
