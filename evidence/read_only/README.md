# Read-only evidence logs

This folder contains selected CR5 30004 feedback captures, DM4310/RS485 read-query diagnostics, and U-Arm/Dobot preview and simulation records. The source workspace also contained robot motion, motor enable, error-clear, configuration-write, control-stream, and screenshot records; those were not copied here. These logs contain machine telemetry and local network addresses; authentication material is not intended to be present.
